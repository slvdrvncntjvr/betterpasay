# Verified Pasay document and service sources

Checked **28 October 2026 (Asia/Manila)** against the live official website and downloads. This is an editorial source inventory, with selected explicitly stated requirements, not an exhaustive application checklist or a guarantee of eligibility, fees, processing time or availability. No applications, logins or payments were submitted.

## How the evidence was checked

The [official homepage](https://pasay.gov.ph/) links service guides and the charter; [Transparency](https://pasay.gov.ph/transparency/) provides the charter/report provenance. Small PDFs were opened and read through the web reader. The large charter exceeded that reader's size limit, so it was downloaded directly using Python Requests with a browser User-Agent, opened with PyMuPDF, searched as text, and relevant checklist pages rendered and visually inspected. The download returned HTTP 200, `application/pdf`, **28,493,768 bytes and 1,193 PDF pages**. Only the relevant sections were reviewed; the entire charter was not audited.

The downloaded [2026 charter](https://pasay.gov.ph/wp-content/uploads/2026/04/pasay-city-citizens-charter-2026.pdf) uses matching printed/PDF page numbers in the sampled sections. Page fragments below open that same full PDF, not smaller extracted files; browser support for jumping to a page varies. Publication dates remain unverified: “2026” is an edition label and upload-folder dates do not establish publication dates.

## Suggested content contract

For each future document/service record, retain: stable ID, resident task name, responsible office, original title, publisher, canonical URL, format, document kind, edition/reporting period, independently verified publication/posting date or `null`, checked date, reviewed pages, selected requirements and limitations. Keep the original source beside every summary. Distinguish `linked`, `metadata reviewed` and `section reviewed`; never replace those with an unqualified “verified” badge.

Where only a charter guide is available, display “Official service guide · PDF · full charter, about 28.5 MB” and a page link. Let residents read the description before downloading a large file. Show separate actions for reading instructions and obtaining a blank form only when both URLs have actually been verified. Review high-change eligibility, fee, deadline and contact claims again before publishing them.
