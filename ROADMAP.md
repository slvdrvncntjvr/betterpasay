# Roadmap

Status: Planned. This roadmap describes intended work; unchecked items have not been completed. Scope and implementation choices will be discussed in repository issues.

## 1. Define the first release

- [ ] Agree on the initial resident needs and a small set of services to document.
- [ ] Identify official Pasay City public sources and record their reuse terms.
- [ ] Define a content format that includes the original source URL, publication date when available, and last verification date.
- [ ] Evaluate community starter templates listed in the Better LGU directory and select an implementation approach.

## 2. Build an initial portal

- [ ] Add application source, local setup instructions, and a reproducible build.
- [ ] Implement accessible navigation and layouts that work on mobile devices.
- [ ] Publish an initial service directory using verified public information.
- [ ] Add source attribution, update dates, and a way to report corrections.
- [ ] Check core functionality, links, accessibility, and deployment configuration.

Once application development starts, update the directory entry to Work in Progress.

## 3. Launch and maintain

- [ ] Deploy the portal and document the deployment process.
- [ ] Review all published information and remove any sample content before launch.
- [ ] Update the Better LGU directory with the live domain and Active status after launch.
- [ ] Establish a regular source review and correction process.

No launch date, domain, or hosting provider has been committed yet.
