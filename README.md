# Better Pasay

A planned, community-led digital transparency portal for **Pasay City, Metro Manila, Philippines**.

Better Pasay aims to make publicly available local government information easier to find, understand, and verify, following the community approach of the [BetterGov.ph LGU Directory](https://github.com/jmacj/better-lgu-directory).

## Project status

**🔵 Planned** — this repository establishes the project and its initial roadmap. Portal implementation has not started. There is no deployed website or application to run yet, and the technology stack has not been selected.

## Planned scope

- A directory of public services, with links to official requirements and contact information.
- Access to public transparency documents and datasets, with original sources and publication dates.
- Clear explanations that distinguish official source material from community summaries.
- A mobile-friendly, accessible interface for residents.

These are proposed areas for the first release, not features currently available. See [ROADMAP.md](ROADMAP.md) for the initial milestones.

## Information standards

- Cite the original public source for each factual entry and record when it was last checked.
- Label missing or unverified information clearly; do not publish invented government figures, contacts, or service requirements.
- Keep sample data visibly separate from verified information.
- Respect source attribution and reuse terms. The code license does not automatically cover third-party documents, datasets, logos, or images.
- Keep personal records, credentials, and non-public information out of the repository.

cd betterpasay

No dependencies, build command, or deployment setup are required at this stage. Setup and deployment instructions will be added when an implementation is selected.
